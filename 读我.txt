Grok Build Desktop —— 读我
============================

这是什么
--------
macOS 桌面端的 Grok Build。内核 100% 是 grok 原生（直接驱动你已装好的
~/.grok/bin/grok，走 ACP 协议），界面是 Claude 暖色主题（暖纸底 + 陶土橙，
亮/暗双色）。grok 会话、工具执行、权限、模型、档位全部是 grok 自己的，
这个壳只做转发和呈现 —— 所以 CLI 里能干的事，这里一样不少。

怎么启动
--------
双击「启动 Grok Build.command」。
- 那个终端窗口就是服务：关掉窗口 = 退出应用。
- 首次运行会自动装依赖（Electron 约 300MB，装到本地缓存目录，不占 OneDrive）。

日常使用（DSH 风界面 + 你的 claude-ui 口味）
------------------------------------------
- 落地页：居中的 ✳ + 居中的输入框（跟 DSH 一样干净），输入框上方两个小胶囊：
  工作目录、提示词预设。直接输入就开聊，第一次会让你选工作目录。
- 输入框内部：左下「⛨ 权限模式」；右下「模型 档位 ⌵」合体控件 ——
  点开一张卡：上半选模型（✓），下半 Effort 滑块（Faster↔Smarter），
  最高一档 Ultracode（紫色能量常流），对应 grok 的 xhigh。
  切模型、调档位运行中即时生效，不用重启；在落地页切好，新会话也会带上。
- 会话列表：按工作区分组（▤），直接读 ~/.grok/sessions，和终端里的 grok
  共用一份历史；右侧显示相对时间。分组标题悬停有「＋」可在该项目直接开新会话。
  顶部 ⌕ 搜索。
- 🗑 删除：真删除，无二次确认，不可恢复（就是你要的那个行为）。
- 思考过程（你的 claude-ui 口味）：安静的一行「Ns · thinking…」，
  点一下能展开斜体思考正文，生成结束整行消失、不留噪音。
  想保留：设置 → 打开「保留思考记录」。
- 聊天页 header：标题 + 工作区 chip + 🤖 模型 chip；右侧引擎状态点
  （绿=运行中，橙闪=生成中，红=挂了，点开看上轮 token / 上下文占用 / 重启）
  和 ❯_ 终端按钮（在系统终端打开 grok TUI，自动 --resume 当前会话）。
- 助手回复悬停有「⧉ 复制」。
- 用量统计（会话/消息/token/连击/高峰时段/常用模型 + 活动热力图）：
  设置 → 用量，可切 全部/30天/7天，数据全部来自 grok 自己的会话记录。
- 输入框敲 / 可以看 grok 的斜杠命令（compact、context、session-info……）。

提示词库（home/prompts/）
------------------------
和你 DSH 的玩法完全一样：
- 一个 .md = 一份提示词 = 预设菜单里的一种模式。
- 第一行「# 标题」= 显示名；模板变量只有 {{model}} 和 {{cwd}}。
- combine.txt 按顺序列文件名（≥2 份）会出现「N 份叠加」预设，
  按顺序拼成一整份，后写的在末尾，模型更听它。
- 预设通过 grok 的 systemPromptOverride 整体替换系统提示词；
  改完文件，下一个新会话生效。
- 选「不用预设」就回到 grok 原生提示词。

密钥卫生（老规矩）
----------------
- home/settings.yaml —— 可同步可截图，密钥只写名字（apiKeyEnv）。
- home/.credentials.yaml —— 0600，只放密钥值，别放进同步盘、别截图。
- grok 官方登录态在 ~/.grok/auth.json，跟这个应用无关，我们不碰。
- 日志全部先脱敏再落盘（sk-/xai- 开头的串、Bearer、长 token 都会打码）。

权限模式（设置里）
----------------
- 每次询问 / 只读自动放行 / 全部自动批准。
- 注意：你机器 ~/.grok/config.toml 里是 permission_mode = "always-approve"，
  grok 根本不会把权限请求发过来。想让 GUI 接管审批，把那行改掉或删掉。

操控电脑（Computer Use）
----------------------
- 设置 → 权限 → 「操控电脑」打开后，Grok 能截你的屏、动鼠标、敲键盘。
- **只对新对话生效**（工具是会话创建时注入的），而且**模型必须是 Grok 4.6**
  —— 实测 4.5 收得到截图但根本不看，会自己编一个画面。
- 还要在系统设置 → 隐私与安全性 里给「启动本应用的那个程序」授两个权：
  屏幕录制（截图）和辅助功能（鼠标键盘）。用 .command 启动就是授权给「终端」。
  设置页里直接显示这两项的真实状态，没授权有「去授权」按钮。
- 官方没有这个功能（查证过：grok CLI 不提供本地 GUI 操控），这是本项目自己写的
  MCP 服务器，代码和详细说明在 computer-use/（含 computer-use/读我.txt）。
- ⚠️ 这是能真的操作你电脑的能力：截图会进模型上下文和 grok 的会话记录，
  屏幕上的网页内容对模型来说是不可信输入。不用的时候把开关关掉。

文件都在哪
----------
- 应用代码：这个文件夹（main/ 主进程，renderer/ 界面）。
- 操控电脑：computer-use/（MCP 服务器 + Swift 输入执行器 + 自测 + 说明）。
- 你的数据：home/（prompts/、settings.yaml、.credentials.yaml）。
  想搬家：设环境变量 GROK_DESKTOP_HOME 指到新位置。
- 日志：~/Library/Application Support/Grok Build Desktop/logs（7 天自动清）。
- 依赖：node_modules 是个软链接，真身在 ~/Library/Caches/GrokBuildDesktop，
  防止 OneDrive 同步 300MB 的 Electron。

出问题了
--------
1. 白屏/起不来：看日志（设置 → 日志），或在终端跑
   GROK_DESKTOP_DEBUG=1 双击启动器 看输出。
2. 「grok 引擎进程退出了」横幅：点重启引擎；多半是 grok 登录过期，
   去 设置 → 账号 点「登录」重新授权（会开浏览器，不弹终端）。
3. 界面卡在「引擎未运行」：确认 ~/.grok/bin/grok 还在、能跑 grok --version。
